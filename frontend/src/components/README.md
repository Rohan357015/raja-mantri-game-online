# Components Guide

- `homepage.jsx` - Main menu. Create room, join room, view current room, or leave current room.
- `createroom.jsx` - Host form for creating a room.
- `joinroom.jsx` - Player form for joining a room.
- `getroom.jsx` - Lobby screen before the game starts.
- `gamepage.jsx` - Main gameplay screen: cards, guesses, scoring, leaderboard, home/leave, and play-again.
- `styles/` - CSS files matched to the screen components.

These files are route-level screens. Smaller reusable UI components can be added here later if the screens grow.
